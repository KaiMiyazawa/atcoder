# atcoder

AtCoder の提出コードと解法メモをまとめたアーカイブです。ABC 系の問題を中心に、Python / C++ / C の解答を残しています。

## 構成

- `ABCxxx/`: コンテスト単位の問題解法
- `*_mine` / `*_not_mine`: 自力解答と比較用メモ
- `README.md`: 全体の入口

## ねらい

- 解法の試行錯誤を後から見返せるようにする
- 言語ごとの実装パターンを残す
- 競プロの継続学習を可視化する

## 備考

- コンテストごとの問題ファイルを追加していく形式
- 必要に応じて解法メモや比較用ファイルを分けて管理
